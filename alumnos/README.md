# Carpeta de alumnos

Esta carpeta es el espacio donde cada estudiante debe guardar su proyecto personal del curso de HTML y CSS.

## Instrucciones

- Cada alumno debe crear una subcarpeta con su nombre.
- Dentro de esa carpeta debe subir su versión del proyecto final del módulo 03.
- Se recomienda incluir los archivos:
  - `index.html`
  - `style.css`
  - `README.md` opcional

## Ejemplo de estructura

```text
alumnos/
├── README.md
├── ana-lopez/
│   ├── index.html
│   ├── style.css
│   └── README.md
├── carlos-ramirez/
│   ├── index.html
│   ├── style.css
│   └── README.md
└── ...
```

## Reglas importantes

- No trabajes directamente dentro de esta carpeta raíz.
- Crea una carpeta individual por alumno.
- Mantén el nombre de la carpeta claro y consistente.
- Subir solo archivos del proyecto y evitar archivos temporales.

## Objetivo

Aprender a trabajar en un repositorio real, organizar archivos por estudiante y colaborar con buenas prácticas usando ramas y Pull Requests.
