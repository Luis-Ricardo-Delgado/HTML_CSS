# Curso de HTML y CSS

Este repositorio contiene un curso práctico y progresivo para aprender los fundamentos de HTML y CSS, pensado para estudiantes que quieren empezar a desarrollar páginas web con una base sólida y ejemplos sencillos.

## Descripción

El curso está organizado en cuatro partes principales:

- [01_html_basico.md](01_html_basico.md): introducción a la estructura de páginas web con HTML.
- [02_css_basico.md](02_css_basico.md): estilos, colores, cajas, flexbox y diseño responsivo con CSS.
- [03_proyecto_final.md](03_proyecto_final.md): proyecto integrador para crear una landing page moderna.
- [04_colaboracion_pull_request.md](04_colaboracion_pull_request.md): trabajo colaborativo con GitHub, ramas y Pull Requests.

## Objetivo del curso

Al finalizar este curso, podrás:

- comprender la diferencia entre HTML y CSS
- crear páginas web con estructura semántica
- aplicar estilos visuales a elementos de una página
- trabajar con layouts básicos usando flexbox
- desarrollar una página web simple y responsiva
- aplicar los conocimientos en un proyecto final personalizable

## ¿Qué aprenderás?

### HTML

- estructura básica de una página
- encabezados, párrafos y listas
- enlaces e imágenes
- formularios y tablas
- etiquetas semánticas como header, nav, main, section y footer

### CSS

- selectores básicos
- colores y tipografías
- modelo de caja
- alineación y espaciado
- botones y estados hover
- flexbox
- media queries para diseño responsivo

## Requisitos

- navegador web

## Organización recomendada

La carpeta `alumnos/` ya quedó creada en el repositorio para que cada estudiante trabaje dentro de ella. Sin embargo, cada alumno debe crear su propia subcarpeta con su nombre y guardar ahí su proyecto final.

```text
HTML_CSS/
├── 00_indice.md
├── 01_html_basico.md
├── 02_css_basico.md
├── 03_proyecto_final.md
├── 04_colaboracion_pull_request.md
├── README.md
├── .gitignore
├── alumnos/
│   ├── ana-lopez/
│   │   ├── index.html
│   │   ├── style.css
│   │   └── README.md
│   ├── carlos-ramirez/
│   │   ├── index.html
│   │   ├── style.css
│   │   └── README.md
│   └── ...
└── .vscode/
```

> Importante: la carpeta `alumnos/` es la raíz compartida del repositorio, pero cada estudiante debe crear su propia carpeta dentro de ella. No todos deben trabajar en la misma carpeta.

## Metodología de estudio

Para aprovechar mejor el curso:

- lee cada archivo en orden
- copia los ejemplos a tus propios archivos
- modifica el contenido para practicar
- intenta crear versiones personales antes de mirar soluciones
- aplica lo aprendido en un proyecto propio

## Regla de oro

- HTML define la estructura y el contenido.
- CSS define la apariencia y el diseño.

## .gitignore

Se recomienda incluir un archivo `.gitignore` para evitar subir archivos innecesarios al repositorio, como:

- archivos del sistema operativo (`.DS_Store`)
- configuraciones locales de VS Code (`.vscode/`)
- archivos temporales
- carpetas de dependencias como `node_modules/`

Esto mantiene el proyecto limpio y profesional.

## Proyecto final

El proyecto final consiste en crear una landing page con:

- encabezado con navegación
- sección de presentación
- tarjetas informativas
- formulario de contacto
- diseño adaptable a dispositivos móviles
