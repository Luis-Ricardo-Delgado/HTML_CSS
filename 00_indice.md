# Curso rápido de HTML y CSS

Este curso está pensado para estudiantes de licenciatura que quieren aprender lo esencial de HTML y CSS con ejemplos pequeños, prácticos y fáciles de seguir.

## Objetivo

Al terminar este curso podrás:
- crear una página web con estructura HTML
- dar estilo con CSS
- entender la diferencia entre contenido y presentación
- construir una pequeña landing page o proyecto académico simple

## Cómo usar este curso

1. Lee cada archivo en orden.
2. Copia los ejemplos en archivos nuevos.
3. Ábrelos en el navegador para ver el resultado.
4. Modifica algunas partes para practicar.
5. Intenta hacer tus propios cambios antes de mirar la solución completa.

## Estructura del curso

- [01_html_basico.md](01_html_basico.md): introducción a HTML
- [02_css_basico.md](02_css_basico.md): introducción a CSS
- [03_proyecto_final.md](03_proyecto_final.md): proyecto práctico final

## Requisitos

- Un navegador web
- Un editor de texto o VS Code
- 1 carpeta para guardar tus archivos

## Primera estructura de proyecto

Crea una carpeta llamada `HTML_CSS` y dentro de ella crea archivos como:

```text
HTML_CSS/
├── index.html
├── style.css
└── README.md
```

## Regla de oro

- HTML = estructura y contenido
- CSS = diseño y estilo
